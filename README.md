# Website chúc mừng sinh nhật Như Ý

## Cách mở trong Visual Studio Code

1. Mở thư mục `sinh-nhat-nhu-y` bằng Visual Studio Code.
2. Cài tiện ích **Live Server** nếu máy chưa có.
3. Nhấp chuột phải vào `index.html` → **Open with Live Server**.

Bạn cũng có thể mở trực tiếp tệp `index.html` bằng Chrome hoặc Edge.

## Chỉnh sửa nhanh

- Đổi tên người nhận: tìm và thay toàn bộ chữ `Như Ý` trong `index.html`.
- Đổi lời chúc: sửa mảng `wishes` trong `script.js`.
- Đổi màu: sửa các biến màu ở dòng đầu tiên của `style.css`.

Trang web không cần máy chủ và không cần tải thêm hình ảnh hay nhạc.
